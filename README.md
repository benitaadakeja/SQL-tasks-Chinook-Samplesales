# SQL-tasks-Chinook-Samplesales


This repository contains two beginner-to-intermediate SQL data analysis projects completed as part of my data analytics learning journey and internship practice.
The projects focus on extracting business insights, performing exploratory data analysis (EDA), and answering real-world business questions using SQL.

---

# 📂 Projects Included

## 1. Chinook Database Analysis 🎵

The Chinook database is a digital media store dataset containing information about customers, invoices, tracks, artists, employees, and sales.

### 🔍 Objectives

* Explore customer purchasing behavior
* Analyze revenue performance
* Identify top-selling genres and artists
* Understand geographic sales distribution
* Practice SQL joins, aggregations, subqueries, and filtering

### 🛠 Skills Used

* SQL Joins
* GROUP BY & Aggregations
* Subqueries
* CASE Statements
* Sorting & Filtering
* Business Insight Generation

### 📊 Key Insights

* The USA had the highest number of customers.
* Rock music generated the most sales.
* A small group of customers contributed significantly to total revenue.
* Certain countries showed stronger purchasing activity than others.

---

## 2. Sample Sales Data Analysis 📈

This project analyzes a retail sales dataset to uncover trends in revenue, customer behavior, and product performance.

### 🔍 Objectives

* Analyze overall sales performance
* Identify top customers and high-performing products
* Study sales trends over time
* Explore regional performance
* Generate business recommendations from data

### 🛠 Skills Used

* SQL Aggregations
* Window Functions
* Date Functions
* Ranking & Sorting
* Revenue Analysis
* Data Cleaning

### 📊 Key Insights

* A few customers contributed a large percentage of total revenue.
* Some product categories consistently outperformed others.
* Sales fluctuated across different months and regions.
* Revenue concentration revealed opportunities for customer retention strategies.
